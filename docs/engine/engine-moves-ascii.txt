State Carried By Each Move
--------------------------

BuyMove
  extends -> Move
  stores -> DevelopmentCard card
  stores -> Map<GemColor, Integer> paymentTokens
  stores -> boolean fromReserved

ReserveMove
  extends -> Move
  stores -> DevelopmentCard card
  stores -> int cardLevel

TakeDifferentMove
  extends -> Move
  stores -> Map<GemColor, Integer> tokens

TakeSameMove
  extends -> Move
  stores -> Map<GemColor, Integer> tokens

PassMove
  extends -> Move
  stores -> no extra state

ReturnTokensMove
  extends -> Move
  stores -> Map<GemColor, Integer> tokens


Factory / Dependency Notes
--------------------------

Move
  depends on -> DevelopmentCard
  depends on -> GemColor
  depends on -> Map<GemColor, Integer>
  creates -> BuyMove, ReserveMove, TakeDifferentMove,
             TakeSameMove, PassMove, ReturnTokensMove

All concrete move classes
  are immutable after construction
  return defensive copies for token/payment maps


Usage Summary
-------------

Validation package
  checks concrete Move subclasses to decide legality.

Turn package
  executes state changes based on concrete Move data.

UI / AI / Network layers
  create Move instances and submit them into engine services.
