Behavior / Dependency Flow
--------------------------

computePaymentTokens(player, cost)
   |
   +--> reads Player bonus counts
   +--> reads Player token counts
   +--> computes remaining colored-token need after bonuses
   +--> fills any shortfall with GOLD tokens
   |
   v
returns payment map

canAfford(player, cost)
   |
   +--> calls computePaymentTokens(player, cost)
   +--> checks whether required GOLD is available
   |
   v
returns true / false


Notes
-----

- PaymentCalculator is a stateless utility class.
- It does not mutate Player or GameState.
- It depends only on Player data, GemColor keys, and cost maps.
- It is used by validation, AI move generation, and turn execution helpers.
