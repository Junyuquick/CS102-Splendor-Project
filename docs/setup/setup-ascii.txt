Setup UML
=========

Setup Flow
----------

            +----------------------+
            | GameStateFactory     |
            +----------------------+
            | - config             |
            | - deckFactory        |
            | - nobleFactory       |
            +----------------------+
            | + createGame(...)    |
            | - createBank(...)    |
            | - buildInitialGems() |
            | - buildGemCounts()   |
            +----------+-----------+
                       |
            +----------+----------+
            |                     |
            v                     v
   +------------------+   +----------------------+
   | DeckFactory      |   | NobleFactory         |
   +------------------+   +----------------------+
   | + buildDecks(...)|   | + buildNobles(...)   |
   | - shuffled(...)  |   | - shuffled(...)      |
   | - fallback cards |   | - fallback nobles    |
   | - mapCost(...)   |   | - mapCost(...)       |
   | - toCost(...)    |   | - toCost(...)        |
   +--------+---------+   +----------+-----------+
            |                        |
            v                        v
   +------------------+     +------------------+
   | CardLoader       |     | NobleLoader      |
   +------------------+     +------------------+

Setup Output
------------

GameStateFactory.createGame(...)
   |
   +--> GemBank
   +--> Board
   +--> GameState


Per-Class Notes
---------------

GameStateFactory.java
  coordinates startup and builds a fresh GameState for a supplied player list

DeckFactory.java
  loads card decks from CSV or falls back to built-in sample card sets

NobleFactory.java
  loads nobles from CSV or falls back to built-in noble sets based on the
  selected fallback profile
