Behavior Summary
----------------

AbstractSwingSplendorFrame.java
  shared base frame for common layout, card/token rendering,
  selection state, pending-move construction, and action wiring

SingleplayerSwingApp.java
  local game UI for human vs AI and same-laptop multiplayer
  resolves turns locally through engine services

MultiplayerSwingApp.java
  network client UI
  listens for server messages, renders lobby/game state, and submits moves

SwingAssetLoader.java
  loads and scales card, token, and noble images with project-local fallbacks

SwingPlayerPanelSupport.java
  builds single-player panels and pre-game lobby panels

SwingPlayerSummaryFormatter.java
  formats player data for rich HTML and compact text summaries

SwingUiTheme.java
  central theme colors, borders, dimensions, and style helpers

SwingConfigSupport.java
  tiny Swing-specific wrapper around config loading

SwingInteractionMode.java
  singleton-style value class describing the current input mode
