Per-Class Notes
---------------

CardLoader.java
  reads tiered card CSV data and returns
  Map<Integer, List<DevelopmentCard>>

NobleLoader.java
  reads noble CSV data and returns List<NobleTile>

Shared parsing concepts
  both loaders validate CSV structure and convert color / cost data into
  domain objects instead of exposing raw rows to the rest of the app
