Per-Class Notes
---------------

GameState.java
  top-level snapshot of the whole match
  stores ordered players, shared board and bank, current-player index,
  and the final-round flag

Player.java
  stores one player's name, token inventory, purchased cards,
  reserved cards, nobles, and derived prestige / bonus information

Board.java
  stores visible market cards, hidden decks, available nobles,
  a board-side gem-count view, and the shared GemBank reference

GemBank.java
  stores and mutates the shared token inventory

DevelopmentCard.java
  immutable card value object with id, level, prestige, bonus color, and cost

NobleTile.java
  immutable noble value object with id, prestige, and requirement

Cost.java
  color-keyed cost container with map conversion helpers

GemColor.java
  serializable singleton-style value class for token colors
  provides static instances and values(), not a Java enum
