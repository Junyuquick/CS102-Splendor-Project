UI / Dependency Notes
---------------------

ClientMain
  shows the connection dialog
  optionally starts a local GameServer for host mode
  launches MultiplayerSwingApp after a successful connect
  depends on -> GameClient, GameServer, MultiplayerSwingApp, Swing UI classes

GameClient
  hides raw socket and object-stream details from the UI
  stores the latest server snapshot and local player index
  depends on -> Socket, ObjectInputStream, ObjectOutputStream,
                NetworkMessage, Move, GameState


Simple Client Sequence
----------------------

ClientMain
   |
