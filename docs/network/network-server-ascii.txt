+----------------------+
   |
   | resolveTurn(...)
   v
+----------------------+

+----------------------+

   | result

+----------------------+
| ServerBroadcaster    |
+----------------------+
   |
   | broadcastState / gameOver / lobby
   v
all connected clients


Per-Class Notes
---------------

GameServer.java
  central multiplayer coordinator
  accepts sockets, manages lobby state, starts games, validates turn
  ownership, delegates turn resolution to the engine, and resets back to
  lobby mode after a finished game

LobbyManager.java
  owns the connected-client roster and lobby rules
  builds Player objects and lobby display names in connection order

ServerBroadcaster.java
  sends shared server messages to the lobby or rejects extra sockets

ClientHandler.java
  one runnable per connected socket
  enforces the JOIN-first handshake and forwards later messages into
  GameServer
