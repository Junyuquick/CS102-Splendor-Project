Protocol Dependencies
---------------------

NetworkMessage
   |
   +--> Move
   |
   +--> GameState
   |
   +--> List<String>


Typical Message Flow
--------------------

client                          server
------                          ------
JOIN            ------------->  handleJoin
JOIN_ACK         <-------------  assign lobby index
LOBBY_UPDATE     <-------------  send lobby state
START_REQUEST    ------------->  host asks to start
GAME_START       <-------------  initial state + player index
MOVE             ------------->  handleMove
STATE_UPDATE     <-------------  new state snapshot
GAME_OVER        <-------------  winner announcement
ERROR            <-------------  invalid request / protocol issue
DISCONNECT       ------------->  remove client


Per-Class Notes
---------------

NetworkMessage.java
  shared serialized wire-format object for the multiplayer protocol
  uses named factory methods instead of public constructors
  current implementation uses string constants, not an enum
